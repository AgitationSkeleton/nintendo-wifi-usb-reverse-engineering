Decoded register/USB init sequence of the ORIGINAL vendor driver
===============================================================
Produced by decoding a USB capture of the original Windows XP driver bringing the
dongle up as a SoftAP. This is our own decoding of observed bus traffic (factual
register reads/writes) -- no vendor code or binary is reproduced here.

Format:  <step>  <R|W>  <register>  <= value        (R = read, W = write)
Register names with '?' are the decoder's best guess; trust the explicit hex
offsets over the guessed names. Banks: MAC_CSR 0x0400+, TXRX_CSR 0x0440+,
SEC_CSR 0x0480+, PHY_CSR 0x04c0+, STA_CSR 0x04e0+.

The device's MAC/BSSID values are redacted; they are read from EEPROM at runtime.
See ../TECHNICAL.md for what these registers mean.
